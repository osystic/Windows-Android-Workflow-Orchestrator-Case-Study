# Engineering Lessons

1. Import UX should match the user's natural data format.
2. Validate an entire batch before mutating persistent state.
3. Never treat imported records as automatically approved execution tasks.
4. Check environment readiness before claiming records.
5. Android UI actions require precise, observable state readback.
6. Unknown outcomes around irreversible actions require durable pre-attempt protection.
7. Keep unit, GUI, package and external-provider acceptance separate.
8. Preserve approved engineering baselines as immutable sources for separately scoped future work.
