# Technical Overview

**Core:** Windows WPF desktop console built with .NET 8 and C#.

**Data:** keyed, validated file inputs; exact normalized phone matching; transactional Pending task creation; transient sensitive details separate from persistent task metadata.

**Emulation:** supported LDPlayer discovery and ADB readiness checks with deliberate single-record assignment per selected instance.

**Inspection:** Android accessibility hierarchy snapshots, recognized screen patterns and uniquely verifiable controls.

**Safety:** manual checkpoints, fail-closed behavior, visible status, durable one-shot attempt ledger and no unattended next-record cycling.

**Quality:** xUnit regression tests, actual Windows synthetic WPF import tests and independent encrypted archive checks.

Implementation and confidential workflow definitions are not publicly released.
